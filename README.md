# Satisfactory calculator
Satisfactory calculator is a desktop app I developed to help me plan out factories in the game [Satisfactory](https://www.satisfactorygame.com/). <br/>
I developed this project purely for fun in my spare time using Unity 6.<br/>
Full disclosure: I added every recipe to the project as a ScriptableObject, by hand.

## Features
### Recipes
Selecting an output in the bottom right will generate a tree-like structure showing which machines are necessary to go from base materials to desired product. <br/>
Every item has a recipe containing only the first level of 'direct' ingredients, which in turn have their own recipe. This way any item can have it's recipe daisy-chained back to the base materials required.
<img src="https://github.com/NielsdeGruijl/SatisfactoryCalculator/blob/main/ReadMeAssets/RotorShowcase.gif"/>

Even the largest recipes in the game can be planned out using this tool. <br/>
The tree-like structure is generated by placing ingredients in a vertical layout group adjacent to their 'parent' item which is also in a vertical layout group. Once all of the ingredients have been placed, lines are drawn from ingredients to their 'parent' item to visualize the recipe.
<img src="https://github.com/NielsdeGruijl/SatisfactoryCalculator/blob/main/ReadMeAssets/BallisticWarpDriveShowcase.gif"/>

### Tabs
The tabs feature allows for planning out multiple factories simultaneously without losing progress.
<img src="https://github.com/NielsdeGruijl/SatisfactoryCalculator/blob/main/ReadMeAssets/FusedModularFrameShowcase.gif"/>

### Alternate recipes
Satisfactory has 'alternate' recipes that alter the way certain items are crafted. In the calculator, alternate recipes can be toggled from the button in the bottom left.
The factory plan updates in real-time as alternates are selected and de-selected.
<img src="https://github.com/NielsdeGruijl/SatisfactoryCalculator/blob/main/ReadMeAssets/AlternatesShowcase.gif"/>

## Improvements
I am pretty happy how this turned out for a fun little side-project. <br/>
If I ever were to return to this project, however, there would be two main improvements I'd add:
- Add a search bar when selecting recipes, especially for the alternate recipes.
- Save data between sessions so you don't have to redo your plans every time you boot up the calculator.
